# Agent Operations v0.1.0

The first public release provides durable execution, exact-action approval and external result verification for API and browser operations.

Try the [local lost-response demo](https://github.com/ArtAndrew/agent-operations/blob/v0.1.0/docs/quickstart.md): the supplier stores an order and drops the response; the worker checks the saved result and completes with one dispatch. No signup or paid model is required.

## Included

- Versioned operations and JSON Schema inputs; HTTP, browser, structured-model and transform steps.
- PostgreSQL-backed state, action ledger, worker leases and recovery.
- Human review tied to a resolved action and connection binding.
- Visible uncertain outcomes, read-only reconciliation and evidence-based manual resolution.
- Workspace roles, encrypted connector secrets, usage counters and audit inspection.
- Dashboard, TypeScript/Python SDKs and tested LangGraph/browser-use examples.

## Downloads

Use the Linux AMD64 or ARM64 Docker archive matching your machine, or install the Python wheel / TypeScript tarball directly from this release. `SHA256SUMS` lists the asset hashes. [Installation instructions](https://github.com/ArtAndrew/agent-operations/blob/v0.1.0/docs/prebuilt.md).

The release workflow verifies the application, browser journeys, framework integration examples and both native container architectures before publication. It checks installation and import of the packaged SDKs.

## Boundaries

This is an early release. It does not promise universal exactly-once effects, production capacity, SSO, billing, autonomous browser planning, or multi-region operation. Provider-specific verification contracts and production isolation remain the operator's responsibility. [Execution semantics](https://github.com/ArtAndrew/agent-operations/blob/v0.1.0/docs/execution.md).

The server/dashboard are source-available under ELv2. SDKs and examples are Apache-2.0; dependencies retain their licenses.
